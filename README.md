# Save & Teleport Menu

A Roblox LocalScript that creates a toggleable menu with Save and Teleport functionality.

## Features

- Toggleable menu with a hamburger (☰) button
- Save your current position
- Teleport back to your saved position
- Persists across respawns (`ResetOnSpawn = false`)

## Setup

1. In Roblox Studio, create a **LocalScript** inside `StarterPlayerScripts`
2. Copy the contents of `SaveTeleportMenu.lua` into the LocalScript
3. Play the game — the menu appears on the left side of the screen
